# Brew day @ September 17th, 2023

I brewed a Wet Hops Blonde Ale with Willamette hops harvested the other weekend.

Not that green anymore, but fresh enough.

I added a bit more late hops than last year as to get mor hop flavours, and let
the worth and aroma hops cool over night as to save some tap water for the
immersion cooler.
