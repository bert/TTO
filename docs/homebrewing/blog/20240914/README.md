# Hops harvest day @ September 14th, 2024

This year's harvest was mostly Willamette hops.

A small amount of Bramling-X hops was intertwined with the Willamette and
could not be kept separate, unfortunately.

All together it was 1123 grams (wet), of which 180 grams went in the wet hops
brew of tomorrow, and the rest was dried, vacuum sealed and stored in
the freezer (189 grams dry).
