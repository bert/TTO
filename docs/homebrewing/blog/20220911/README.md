# Hops harvest day @ September 11th, 2022

This first year's harvest was mostly Willamette hops, 1325 grams (wet).

The Bramling-X gave me 833 grams (wet) last week, of which 160 grams went in the
[Wet Hops Blonde Ale Bramling-X](../20220904/README.md) brew.

160 grams Willamette hops goes in the Wet Hops Blonde Ale brew of next week.

All together it was 2158 grams (wet).

The rest of the hops was dried, vacuum sealed and stored in the freezer.
