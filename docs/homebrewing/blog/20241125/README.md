# Brew day @ November 25th, 2024

I brewed an Ukrainian Golden Ale based on a style description I found on the
[internet](https://lana-svitankova.blogspot.com/2022/03/ukrainian-golden-ale-we-need-more-gold.html).

Made up a recipe with local available ingredients and selected a neutral yeast
as mentioned in the article.

Something like this came out:

Refuse/Resist (Ukrainian Golden Ale)

Style: Ukrainian Golden Ale

ABV: 7.9 %

IBU: 21

EBC: 15.8

Original Gravity: 1.073

Final Gravity 1.013

Batch size: 5 L

## Mash

Source profile: NL Spa Reine Flat Mineral Water (www.ah.nl)

Target profile: Yellow Full - Brun Water (1.25) Profile

| Ca 2+ | Mg 2+ | Na + | Cl - | SO4 2- | HCO3 |     |
|-------|-------|------|------|--------|------|-----|
| 54    | 5     | 5    | 64   | 60     | 17   | ppm |

Strike temperature @ 71 C

40 minutes @ 66 C

20 minutes @ 72 C

10 minutes mash out @ 77 C

1428 grams Castle malting Pale Ale malt

71 grams Brewferm Wheat malt

45 grams Castle Malting Chateau Biscuit malt

## Boil

60 minutes

3.5 grams Cascade T90 (A.A. 7.5 % pellet) @ 0 minutes (12.6 IBU)

3.6 grams Saaz (A.A. 3.6 % pellet) @ 30 minutes (4.5 IBU)

4.8 grams Saaz (A.A. 3.6 % pellet) @ 45 minutes (5.9 IBU)

## Fermentation

7 grams Fermentis US-05 yeast

Primary @ 17 C for 10 days

Diacetyl rest @ 21 C for 4 days

## Bottling

27 gram Table Sugar for 2.0 % carbonation

## Carbonation

Carbonation @ 18 C for 14 days

## Conditioning

Conditioning @ 18 C for 28 days
