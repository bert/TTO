# Bottling day @ July 20th, 2026

Bottled the Old Ale tonight ... 3 split batches for a total of 6 L
bottled out of 6.48 L post boil volume, so I lost a pint in the dredges
of the yeast cake.
 
OG was 1.060 ... FG varied from 1.004 - 1,009, giving an ABV varying
from 6.7 - 7.4 %.
 
I did some variations with different hops in the hopstand ... the base
was EKG kettle hops, Fuggle late in the boil and then experimenting with
Progress and Goldings in the hopstand.
 
I did a slurp and did not notice any off taste, final tasting in 2 - 3
weeks.
