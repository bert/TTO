# SMaSH Fuggle v3

Style: 02A International Pale Lager

ABV: 4.6 %

IBU: 21

EBC: 7.7

Original Gravity: 1.040

Final Gravity 1.007

Batch size: 5 L

## Mash

Source profile: NL Spa Reine Flat Mineral Water (www.ah.nl)

Target profile: Vienna Lager Profile

| Ca 2+ | Mg 2+ | Na + | Cl - | SO4 2- | HCO3 |     |
|-------|-------|------|------|--------|------|-----|
| 47    | 7     | 51   | 102  | 51     | 68   | ppm |

Strike temperature @ 68.7 C

60 minutes @ 63 C

1000 grams Crisp Extra Pale Ale (Lager) malt

## Boil

60 minutes

5 grams Fuggle (A.A. 5.0 % whole) @ 0 minutes (12.3 IBU)

5 grams Fuggle (A.A. 5.0 % whole) @ 30 minutes (9.1 IBU)

1 grams Irish Moss @ 50 minutes

## Fermentation

0.5 package Fermentis S-23 SafLager West European Lager yeast

Primary @ 13 C for 14 days

Cold crash @ 5 C for 3 days

## Bottling

30 gram Table Sugar for 2.5 % carbonation

## Conditioning

Lagering @ 10 C for 90 days
