# SMaSH First Gold v1

Style: 12A British Golden Ale

ABV: 4.5 %

IBU: 38

EBC: 8

Original Gravity: 1.044

Final Gravity 1.010

Batch size: 5 L

## Mash

Source profile: NL Spa Reine Flat Mineral Water (www.ah.nl)

Target profile: Golden Strong Ale

| Ca 2+ | Mg 2+ | Na + | Cl - | SO4 2- | HCO3 |     |
|-------|-------|------|------|--------|------|-----|
| 33    | 9     | 38   | 76   | 75     | 20   | ppm |

Strike temperature @ 72.1 C

60 minutes @ 66 C stir frequently

1082 grams Crisp Maris Otter Pale Ale malt

## Boil

60 minutes

5.9grams First Gold (A.A. 7.5 %) @ 0 minutes (23 IBU)

7.5 grams First Gold (A.A. 7.5 %) @ 50 minutes (11 IBU)

1 grams Irish Moss @ 50 minutes

## Hopstand

11.2 grams First Gold (A.A. 7.5 %) 20 minutes hopstand @ 75 C (4 IBU)

## Fermentation

0.4 package Wyeast Labs Belgian Abbey Style Ale yeast

Primary @ 20 C for 14 days

## Bottling

30.2 gram Table Sugar for 2.4 % carbonation

Carbonation @ 18 C for 14 days

## Conditioning

Conditioning @ 18 C for 28 days
